# Web de Yulia Suárez · Юлия Суарес

Web oficial de Yulia Suárez, vocalista y vocal coach en Moscú. Diseño SILENCIO «bestia» (v60 profesional), versión 61.

- `index.html`: la web entera, en un solo archivo (RU / ES).
- Contactos: se rellenan en `const CONTACTO` del script, al final de `index.html`.
- Dominio previsto: yuliasuarez.ru (principal) y yuliasuarez.com (redirige). Alojamiento: Beget.
- Regla: no editar a la vez desde el Mac y el PC. Antes de cambiar, `git pull`; después, commit y push.
- Fotos, vídeos y opiniones se añaden solo con material real.
